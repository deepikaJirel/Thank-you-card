THANK YOU EMMA — INTERACTIVE WEBSITE

FILES
- index.html : the webpage structure and message
- style.css : colors, envelope, animation and responsive design
- script.js : click-to-open, close, confetti, keyboard controls
- thank-you-emma.png : your original thank-you card image

RUN LOCALLY
1. Keep all 4 files together in the same folder.
2. Double-click index.html.
3. Click the envelope or Open your surprise.

CUSTOMIZE
- In index.html, change the text inside <p class="message"> to edit your note.
- Edit the heading or button copy there too.
- In style.css, change colors under :root.

PUBLISH WITH GITHUB PAGES
1. Create a public repo on github.com, for example 'thank-you-emma'.
2. Upload all 4 files to the root of the main branch.
3. Go to Settings > Pages > Build and deployment > Deploy from a branch.
4. Select main and / (root), then Save.
5. The shareable address will typically be https://YOUR-USERNAME.github.io/thank-you-emma/
6. Visit the published URL yourself before sharing it.

No JavaScript packages or build commands required. Google Fonts need an internet connection.
